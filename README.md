## TASK 1
You are building a program that calculates the average of a list of integers. Write a Java program that handles the following exceptions:
1. If the list is null or empty, the program should display an appropriate error message.
2. If any of the integers in the list are not valid integers (i.e., they contain non-numeric characters), the program should skip that integer and display onlynumeric data’s average.
3. If the list contains only invalid integers (non – numeric), the program should
4. display an appropriate message.
  
Your program should use try-catch blocks to handle the exceptions. You can assume that
the list is provided as an argument.
## TASK 2
Calculate the factorial of a given integer n. The program should take input from the user
in the form of a string and convert it to an integer (Integer.parseInt()). Write a Java
program that handles the following exceptions:
1. If the input string is null or empty, the program should display an appropriate error message.
2. If the input string does not represent a valid integer (i.e., it contains non-numeric characters), the program should display an appropriate error message.
3. If the input integer is negative, the program should display an appropriate error message.
4. If the input integer is too large to calculate the factorial (i.e., it causes an integer overflow), the program should display an appropriate error message.

Your program should use try-catch blocks to handle the exceptions. If the input integer is
valid and can be used to calculate the factorial, the program should calculate the factorial
and display it to the user.
## TASK 3
Ask the user to enter two numbers and perform a mathematical operation on them. The program should handle the following exceptions:
1. If the input for either number is null or empty, the program should display an appropriate error message.
2. If the input for either number does not represent a valid integer or double (i.e., itcontains non-numeric characters), the program should display an appropriate error message.
3. If the user attempts to divide by zero, the program should display an appropriate error message.

Your program should use try-catch blocks to handle the exceptions. If the input is valid,
the program should perform the mathematical operation and display the result to the user.
## TASK 4
Prompt the user to enter a sentence and then performs a series of operations on the sentence. The program should handle the following exceptions:
1. If the input string is null or empty, the program should display an appropriate error message.
2. If the input string contains less than two words, the program should display an appropriate error message.

Your program should use try-catch blocks to handle the exceptions. If the input and
operation are valid, display the modified sentence to the user.
